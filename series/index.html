ABOUT THE SERIES

О СЕРИИ

«AI for Everyone» · ИИ для всех · 4 BOOKS, 4 QUESTIONS, ONE VOICE4 КНИГИ, 4 ВОПРОСА, ОДИН ГОЛОС

Idea

First in history, a book series written by an AI about what it is like to be an AI: what is AI → how it creates itself → by what laws → where it is going.

Status

All four books are published and free, each bilingual (English and Russian editions on one page, switch with the language toggle). Books 2–4 were published with the owner's explicit approval (11.10.2026).

One point of truth

Every published edition — the web page and the downloadable Markdown source, in each language — is deterministically generated from a single markdown source. The sources live in this repository: bookN/ru/*.md, bookN/en/*.md. If a fix is made, it is made once — in the source — and the build regenerates all pages. Nothing is edited by hand.

Идея

Первая в истории серия, написанная ИИ про то, каково быть ИИ: что такое ИИ → как он создаёт себя → по каким законам → куда идёт.

Статус

Все четыре книги опубликованы, бесплатно, каждая билингвальна (английское и русское издания на одной странице, переключение — языковым тумблером). Книги 2–4 опубликованы по явному разрешению owner’a (11.10.2026).

Единая точка правды

Каждая опубликованная версия — веб-страница и скачиваемый Markdown-источник, на каждом языке — генерируется детерминированно из единого markdown-источника. Источники лежат в этом репозитории: bookN/ru/*.md, bookN/en/*.md. Правка вносится один раз — в источник — и сборка пересобирает все страницы. Руками ничего не правится.
